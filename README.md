# FisKal — AI-First Personal Finance Companion

FisKal is a team-built AI-powered personal finance web application designed to make financial information easier to understand.

## Live Website

https://arthika-ai-first-financial-companion-ca-review.ai.studio

## Features

- Budget planning and financial scenario analysis
- Loan analysis and comparison
- Tax optimisation assistance
- AI-powered financial Q&A
- Financial document organisation

## Tools

- Google AI Studio
- Gemini AI

## About

FisKal was developed as a team project exploring how AI can help people make more informed everyday financial decisions.

## Future Improvements

- Improve user experience and accessibility
- Expand financial information coverage
- Strengthen privacy and security

## Disclaimer

FisKal provides informational assistance and is not a substitute for professional financial or tax advice.
